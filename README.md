# 123云盘多盘合并（P123DiskMulti）

MoviePilot 插件：将**多个 123 网盘账号**合并为一个存储空间使用，支持网盘间文件互传、空间不足自动切换网盘、合并空间显示。

> 本插件基于 [DDSRem](https://github.com/DDSRem) 的 [P123Disk](https://github.com/DDSRem-Dev/MoviePilot-Plugins/tree/main/plugins.v2/p123disk) 插件扩展开发，感谢原作者。

## ✨ 功能特性

| 功能 | 说明 |
| --- | --- |
| 📦 多盘共用 | 任意数量的 123 网盘账号合并为存储「123云盘」，根目录下每个网盘对应一个文件夹 |
| 🔄 网盘间文件互传 | 在整理/移动时选择不同网盘下的目标目录，自动完成跨盘传输（同盘走服务端移动，跨盘走 下载→上传→删除） |
| 🪄 空间不足自动切换 | 上传时目标网盘剩余空间不足（低于预留空间），自动切换到剩余空间最大的网盘上传 |
| 🧮 空间合并显示 | 存储空间使用情况为所有网盘的总和；插件详情页展示合并空间 + 各网盘空间卡片 |
| ⚖️ 一键均衡空间 | 插件页一键将空间紧张的网盘中的文件自动迁移到剩余空间大的网盘 |
| 🎬 多盘 STRM 助手 | 所有网盘通用：302 直链播放、整理入库自动生成 STRM、全量同步、定时同步 |
| 📤 分享增量同步 | 123 分享内容检查 + 服务器端直传转存新文件（云端到云端，不占本地带宽），支持多盘多分享 |
| 🗂️ 定期目录整理 | 定时/手动将指定 123 盘目录内的媒体文件提交到 MoviePilot 整理队列，重命名/刮削/进媒体库遵循 MoviePilot 规则 |
| 🎨 简洁美观的设置界面 | 说明引导 + 卡片式网盘配置 + 可视化空间展示 |

## 📥 安装

MoviePilot「插件市场」→ 添加仓库：`https://github.com/Rst307/P123DiskMulti` → 安装 **123云盘多盘合并**。

依赖 `p123client` 会通过 requirements.txt 自动安装。

## ⚙️ 配置说明

### 网盘账号列表

每行一个网盘，格式：`网盘名称,手机号,密码`

```
我的盘A,13800138000,123456
我的盘B,13900139000,abcdef
```

- **网盘名称**：显示为「123云盘」根目录下的文件夹名，需唯一；修改名称会影响已配置的目录路径，请谨慎修改
- 兼容旧版单盘插件（P123Disk）配置：检测到 `passport/password` 时自动迁移为单个网盘「盘1」

### 其他设置

| 配置项 | 说明 |
| --- | --- |
| 启用插件 | 插件总开关 |
| 空间不足自动切换网盘 | 上传时目标网盘空间不足，自动选择剩余空间最大的网盘 |
| 每个网盘预留空间（GB） | 剩余空间低于该值时视为"空间不足"，触发自动切换；建议 5~20GB |

## 📤 分享增量同步

在插件设置中启用「分享增量同步」后，可以检查 123 分享内容并把新文件增量转存到自己的网盘：

### 分享任务配置

每行一个分享任务，格式：`名称,分享链接或分享码,提取码,目标目录,注释(可选)`（提取码与注释可为空，字段留空即可）

```
东京教父,https://www.123pan.com/s/AbC123-DEF,1234,/盘A/分享/电影,东京教父1080p
剧集分享,Sa7K8-QwEr,,/盘B/分享/剧集,某某剧第一季
```

- **注释（第 5 列，可选）**：会显示在插件详情页的任务卡片上，方便区分多个任务分别对应哪个剧/哪个链接

- **目标目录必须带网盘前缀**（如 `/盘A/分享`），转存到哪个网盘就用哪个网盘的账号
- **转存中目标盘空间不足自动切换**：每批转存前检查目标盘剩余空间（低于预留空间即视为不足），不足时自动切换到剩余空间最大的网盘继续转存（受「空间不足自动切换网盘」总开关控制，目录结构保持不变）；所有网盘均不足时该批文件记失败，下次同步自动重试
- 转存保留分享的目录结构；已转存的文件记录在插件数据目录的 SQLite 中，**只转存新文件**，同名文件增删不重复
- 支持每 6 小时定时增量转存（可自定义 cron，留空则只手动转存）

### 使用方法

1. 插件详情页每个分享任务卡片有「🔍 检查内容」和「⚡ 立刻检测转存」按钮
2. 「检查内容」只验证分享可访问性并统计文件/目录/大小
3. 「⚡ 立刻检测转存」一键完成 **分享内容检测 + 增量转存**（一次遍历分享，不重复请求），后台执行（页面立即返回，不阻塞），完成后卡片显示 可访问性/文件数/总大小 + 扫描/新增/跳过/失败 统计

> 转存使用 123 服务器端直传（`share_fs_copy`，云端到云端），速度与本地网络无关、不占本地磁盘；
> 转存确认通过轮询目标目录完成，未确认的文件自动进入待确认队列，下轮同步自动转正或重传。

## 📖 使用方法

### 目录路径格式

```
/网盘名称/目录
```

例如：

- 下载目录：`/我的盘A/下载`
- 媒体库目录：`/我的盘B/电影`

在「文件管理」中打开存储「123云盘」，即可看到每个网盘对应的文件夹。

> 也可以不写网盘前缀（如 `/电影`），上传时插件会自动分配到剩余空间最大的网盘。

### 网盘间互传

MoviePilot 整理时，源目录和目标目录选择不同网盘下的路径即可自动完成跨盘传输：

- **移动**：自动执行 下载 → 上传 → 删除源文件（若目标盘已存在同内容文件，秒传瞬间完成）
- **复制**：自动执行 下载 → 上传

### 自动切换网盘

开启「空间不足自动切换」后，上传文件时会先检查目标网盘空间：

1. 目标网盘剩余空间 ≥ 文件大小 + 预留空间 → 正常上传
2. 目标网盘空间不足 → 自动选择剩余空间最大的网盘，在该网盘创建相同目录结构后上传
3. 所有网盘均不足 → 上传失败并输出明确日志

### 一键均衡空间

插件详情页点击「⚖️ 一键均衡空间」按钮，自动将空间紧张网盘根目录下最旧的文件迁移到剩余空间最大的网盘。

也可通过 API 调用（需要 API Token）：

```bash
POST /api/v1/plugin/P123DiskMulti/balance
```

## 🎬 STRM 功能（多盘支持）

在插件设置中启用「STRM 功能」后：

1. **302 直链播放**：Emby 播放 .strm 文件时，自动通过插件端点实时换取 123 下载地址并 302 重定向（无需额外配置）
2. **整理入库自动生成**：开启「整理事件监控目录」，MoviePilot 整理入库时自动在本地生成 .strm 文件
3. **全量同步**：扫描所有网盘的媒体目录批量生成 .strm（可手动/定时），覆盖存量文件
4. **多盘通用**：STRM 的 302 换取基于 123 全局文件标识，所有网盘账号通用

### STRM 配置

| 配置项 | 说明 |
| --- | --- |
| MoviePilot 访问地址 | STRM 播放 URL 前缀（需带端口、能被 Emby 访问），如 `http://192.168.1.10:3000` |
| 整理事件监控目录 | 每行 `本地STRM目录#网盘媒体库目录`，网盘目录**必须带盘前缀**（如 `/盘A/电影`） |
| 全量同步目录 | 同上格式，可配置多行多盘 |
| 全量同步定时 | cron 表达式，默认每 7 小时；留空不自动同步（后台执行，可与手动同步自动排队） |
| 覆盖已有 STRM 文件 | 关闭时已存在的 .strm 跳过 |
| 生成后刷新媒体服务器 | 生成后自动刷新 Emby 等媒体库；服务器名称从 MoviePilot 已配置的媒体服务器中**下拉选择**（可多选，留空刷新所有） |
| 风控自动切换换链域名 | 换链后自动探测下载票有效性，通道被风控（CDN 403 50002/1010）时自动切换到另一换链通道，避免全库无法播放（默认开启） |
| 播放票类型 | **VIP 直链**（默认）：账号直链换链，带域名风控自动切换；**分享票**：通过已有分享下载票播放（来源必须是「自分享目录服务」的目录或「分享增量同步」转存入库的文件）；**按需分享**：播放时按 md5+size 定位原文件并创建带有效期的单文件分享，任何自己上传/转存的文件均可播放（不复制文件）；**自动**：分享票优先，失败回退 VIP 直链，再失败按需分享兜底（任何在网盘里的文件都能放） |
| 按需分享有效期（天） | 按需分享模式下自动建的分享有效天数（默认 7）；到期由 123 自动回收，下次播放自动重建 |
| 按需分享提取码（可选） | 留空则自动建的分享无提取码（换票自动完成，无需人工输入）；填写后分享需提取码才能下载 |
| 启用自分享目录服务 | **独立服务**（不依赖分享增量同步）：自动把自己网盘的目录建成 123 分享，自己上传/转存的媒体文件也可走分享票播放 |
| 自分享目录列表 | 每行一个目录：`目录虚拟路径[,提取码(可选)]`，如 `/盘A/电影` 或 `/盘B/剧集,1234`；目录必须是本插件账号网盘内的媒体目录（与 STRM 同步的同一批目录） |
| 定时刷新分享（cron） | 定期校验自分享有效性并重新索引目录内容，默认每 6 小时；留空则不自动刷新（可在插件页手动「重建分享」） |
| 下载链接缓存（秒） | 已验证下载直链缓存时长，默认 600 秒。Emby 每次播放会 HEAD+GET 签两次票，缓存命中即不再签票，显著降低风控触发频率；0 关闭缓存 |
| 下载换链域名（高级） | 每行一个，按优先级尝试；留空用内置默认（`https://api.123278.com/b` 优先，p123client 默认域名兜底）。仅当 123 更换域名或默认通道失效时需调整 |

### 使用步骤

1. 设置中启用 STRM 功能，填写 MoviePilot 访问地址和路径映射
2. 在 Emby 中添加**本地媒体库**，指向「本地STRM目录」
3. 插件页点「⚡ 立即全量同步」生成存量文件的 STRM（**后台默默执行**，页面立即返回，插件页会显示同步进度与上次同步结果；也可等待定时同步）
4. Emby 刷新后即可播放（播放时走 302 直链，不占 Emby 扫描资源）

> 全量同步为后台任务：点击后立即返回，同步在后台线程执行，同一时间只有一个同步任务（手动/定时自动排队）；可通过 `GET /api/v1/plugin/P123DiskMulti/strm_status` 查询状态。

> STRM 内容形如 `http://{MoviePilot地址}/api/v1/plugin/P123DiskMulti/redirect_url?apikey=...&s3_key_flag=...`，播放时实时换取下载地址，123 下载链接的有效期问题已由实时换取解决。

## 🗂️ 定期目录整理

在插件设置中启用「定期目录整理」后，插件会定期（默认每天凌晨 3 点，可改 cron）把指定 123 盘目录内的**媒体文件逐个提交到 MoviePilot 的整理队列**，由 MoviePilot 自带整理链完成重命名、刮削、进媒体库等全部操作。

### 配置

- **整理目录**：每行一个，需带网盘前缀（如 `/盘A/emby_raw`、`/rst307/emby_raw`），递归扫描子目录
- **定时整理（cron）**：默认 `0 3 * * *`（每天凌晨 3 点），留空则不自动整理
- 插件详情页有「立即整理」按钮，可手动触发（后台执行，页面不阻塞）

### 注意事项

- **整理目标由 MoviePilot 的「目录同步」配置决定**：请在 MoviePilot 中为 123 盘目录配置好整理目标（转移目录/媒体库路径），否则会提示「未匹配到整理目录」
- 只提交视频文件（mkv/mp4 等），字幕等附加文件由 MoviePilot 整理链自动同步整理；跳过蓝光原盘结构目录（BDMV）
- 文件提交到 MoviePilot 整理队列后由 MoviePilot 后台执行，已整理过的文件不会被重复整理（自动去重）
- 整理为同盘移动时走 123 服务端秒级 fs_move；跨盘/跨存储时 MoviePilot 自动处理（如 123→本地为下载后移动）
- 整理完成后 MoviePilot 会自动通知媒体服务器刷新
- **整理失败且原因为「媒体库已有同名且质量更好」时，自动删除网盘上的低版本源文件**（移入回收站可恢复，释放空间；可通过「整理失败自动删除网盘低版本文件」开关关闭）

## 📄 常见问题

**Q：为什么文件实际路径和配置的路径不一样？**
自动切换网盘后，文件会上传到其他网盘对应的路径（如配置 `/我的盘A/电影`，实际落在 `/我的盘B/电影`），这是正常行为，转移结果会显示真实路径。

**Q：123 网盘「设备管理」里出现很多登录记录，每次操作都新增登录？**
这是历史版本的已知问题：插件没有复用登录态，每次操作/每次请求遇到 401 都会用账号密码重新登录（123 登录 token 有效期 30 天，本可长期复用），重登产生的 token 越积越多，又触发 123 的「token 数量超限」拦截，形成恶性循环。

v1.4.11 起已修复：

1. 登录 token 持久化到插件数据目录（`p123tokens.json`），重启、重载、日常操作直接复用，不再重复登录；
2. 关闭了客户端库的“任何 401 都自动重登”行为，只有 token 确实失效时才重登；
3. 「token 数量超限」类 401 不再触发重登（重登只会产生更多 token），并提示去设备管理清理；
4. 并发操作共享同一登录态（线程安全），自动重登带 60 秒冷却合并。

如已积累大量无效登录记录，可到 123 网盘「设备管理」手动清理旧设备；清理后插件会用持久化的 token 继续工作，无需重新登录。

**Q：跨盘传输慢怎么办？**
跨盘传输 = 下载到本地临时目录 + 上传，受本地带宽和网速影响；若目标网盘已有同内容文件（秒传），则瞬间完成。建议将常看的媒体放在同一网盘，减少跨盘操作。

**Q：一个网盘挂掉会影响整个存储吗？**
不会。单个网盘查询失败时，浏览、上传、空间统计会自动跳过该网盘（空间统计只汇总可用网盘），并在日志中提示。

**Q：播放时报「download err: 50002 / code 1010」或 HTTP 403 怎么办？**
这是 123 对下载换链通道的风控拦截，常见特征：换链接口本身正常（每次都返回新签名链接），但拿到 CDN 链接下载时网关统一返回 `HTTP 403 {"message":"download err: 50002","code":1010}`，影响账号下所有文件。

原因：123 存在多个换链（签票）通道，**签票身份由换链请求域名决定**（URL 中 `ur` 参数前缀可区分：`yun.123pan.com/b` 签发的为 `vpagiagaelg*` 家族，`api.123278.com/b` 签发的为 `vpngvaegvngvnp` 家族），CDN 按票身份做风控判定，与 IP/UA/账号 token 类型/文件无关。账号在某个通道被风控后，切换另一通道即可恢复（网页端一直可用正是因为前端走 `api.123278.com`）。

v1.4.2 起插件已内置处理：

1. 换链后自动探测票有效性（Range GET 首字节），被风控时自动切换换链域名重试，并输出明确日志（「下载通道被风控…正在尝试切换换链域名」）；
2. 默认优先使用网页通道 `https://api.123278.com/b`（官方域名，与 123pan.com 同一备案主体）；
3. 已验证域名按账号记忆 30 分钟，避免每次播放都重复踩被风控的通道；
4. 可通过「下载换链域名」自定义候选（每行一个）。

若两个通道都失败，日志会提示「所有换链域名均失败」，此时通常是账号级风控或网络出口问题，可尝试：更换服务器出口 IP、等待一段时间后重试，或联系 123 客服（官方未公开 50002 的自动解封时长与申诉渠道）。

**Q：分享票模式怎么用？与 VIP 直链有什么区别？**

**原理**：VIP 直链模式下，每次 STRM 播放 = 一条账号直链被外部 IP 下载，这正是 123 防盗链风控的典型特征，长期运营必然反复触发（50002/1010）。分享票模式改用 123 的**分享下载票**（`share/download/info`）播放：分享下载本就是「任何人免登录、多 IP 下载」的设计内行为，多 IP 播放不再是异常信号；最坏情况是单条分享链接被风控，**重建分享即可，账号不受影响**。

**使用前提**：文件必须能反查到一条分享记录——两条途径：① **自分享目录服务**：把自己网盘的媒体目录配置为自分享，插件自动建分享并索引（自己上传的文件也适用，与分享增量同步完全独立）；② **分享增量同步**：文件是经插件转存他人分享入库的。直接上传且未配置自分享的文件没有分享记录，分享票模式无法播放（自动模式会回退 VIP 直链）。

**配置**：设置 → 播放票类型 → 选择「分享票」（只走分享通道）、「自动」（分享票优先 → VIP 兜底 → 按需分享兜底）或「按需分享」。分享票自动按票内 `t` 参数有效期缓存复用；被 CDN 风控（403）时自动丢弃旧票重新换票重试一次。

> **提示**：分享票模式只认分享转存记录，如果日志出现「分享 XX 内未找到路径（分享可能已失效/已重建）」，说明该文件的转存记录已失效（来源分享被重建/改动），此时播放请改用「按需分享」或「自动」模式——按需分享会直接在你自己的网盘里按 md5+size 定位原文件并原地分享，不依赖任何分享记录，也不会复制文件。

**注意事项**：
- 分享者撤链/分享被风控 → 该分享下所有票失效，日志会提示「分享源文件不存在（400）…请更新分享链接或重新转存」；运营侧建议定期重建分享链接（重建后重新同步一次，新记录自动覆盖旧记录）；
- 分享票要求登录态（无 token 会报 5112），插件用已配置账号的 token 换取；
- 若日志提示「分享 CDN 地域绑定拦截（realc/city）」，与 VIP 模式同类，检查 MoviePilot/Emby 网络出口地域一致性。

**Q：按需分享（懒建分享）模式是什么？和分享票/自分享目录有什么区别？**

**按需分享**是第三种分享票玩法：播放时插件自动完成「定位文件 → 创建只含该文件的分享（带有效期，默认 7 天，到期由 123 自动回收）→ 换分享票 → 播放」。

| 模式 | 需要什么 | 建分享时机 | 适合场景 |
| --- | --- | --- | --- |
| 分享票 | 文件来自「分享增量同步」转存 | 不建（用源分享） | 库是转存来的 |
| 分享票（自分享目录） | 启用「自分享目录服务」并配置目录 | 预建目录分享 + 索引 | 库是自建目录、文件多 |
| **按需分享** | **什么都不用配** | **播放时懒建，单文件、带有效期** | 任何文件，最省心 |

按需分享的特点：
- 同一文件在有效期内多次播放只建一次分享；到期后下次播放自动取消旧分享并重建
- 单文件分享：最坏情况单条分享被风控（重建即可），账号与其余文件不受影响
- 定位用「全局搜索 + 遍历」直接命中原文件（FileId），**不复制文件、不在根目录产生副本**；文件必须在网盘中（STRM 与网盘数据一致）
- 分享带有效期自动过期，不残留永久分享；提取码可选
- 建议有效期不要设太短（如 1 天），否则热播文件每次播放都重建分享

**Q：自分享目录服务和分享增量同步是什么关系？**

两者是**完全独立的两个服务**，互不依赖，可单独启用：

| | 分享增量同步 | 自分享目录服务 |
| --- | --- | --- |
| 作用 | 把**他人**的分享转存到自己网盘 | 把**自己网盘**的目录建成 123 分享 |
| 数据 | 转存记录（share_files） | 自分享索引（独立表 + 独立 SQLite） |
| 启用 | 分享增量同步开关 | 自分享目录服务开关 |
| 播放 | 分享票反查转存记录 | 分享票反查自分享索引 |

**Q：怎么防止再被风控？**
风控是 123 的账号级策略，阈值不公开，无法 100% 规避；但可以把触发概率降到可忽略，并把故障窗口从「全库瘫痪」缩到「单次请求自愈」。已内置的措施：

1. **默认走网页通道**（api.123278.com/b）：该通道必须为所有网页用户服务，风控最宽松，第三方通道（yun）仅兜底；
2. **降低签票频率（v1.4.3）**：Emby 每次播放会 HEAD+GET 签两次票，重缓冲/反复点播更频繁。已验证直链按文件缓存（默认 10 分钟），缓存命中不再签票，把签票频率降一个量级——这是风控最主要的触发信号；
3. **触发后自动自愈**：被风控通道自动切换，工作域名按账号记忆 30 分钟、失败域名冷却 5 分钟，解封后自动切回；
4. **多账号天然隔离**：本插件支持多盘，域名状态按账号隔离，单账号被风控不影响其他盘的播放。

另外建议从使用侧配合（社区实证的触发因素）：

- **保持 MoviePilot/Emby 出口 IP 稳定**：不要用会切换节点的代理/机场线路；123 会校验换链与下载的 IP 地域一致性（日志里的 `realc/city` 错误即此），地域不一致是典型触发信号；
- **不要用多线程/多连接工具拉直链**（aria2 `-x16` 之类）：同一文件的并发分片请求是经典风控触发信号，Emby 播放本身不会产生；
- 多个 123 账号尽量分摊使用，避免单账号高频签票。

若已被风控（日志出现 50002 且两通道均失败）：**更换出口 IP 是最快的恢复手段**（社区共识），其次是等待；官方未公开自动解封时长，也无公开申诉入口，联系客服只回复开放平台文档。

**Q：日志出现「CDN 地域绑定拦截（forbidden realc:… city arg_c:…）」？**
这是另一类 1010 错误：CDN 校验下载出口 IP 地域与换链方地域一致，与通道风控无关，切换域名无法解决。请确认 MoviePilot/Emby 的网络出口（如代理、机场节点）与换链服务器地域一致。

**Q：如何从旧版 P123Disk 插件迁移？**
安装本插件后填入原手机号/密码即可（存储名称同为「123云盘」，目录配置无需修改）。旧版单盘配置（passport/password）会自动迁移为网盘「盘1」。建议迁移后删除旧插件，避免两个插件同时劫持存储操作。
